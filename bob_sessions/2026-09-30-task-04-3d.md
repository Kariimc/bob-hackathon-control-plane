## What Bob built

### .bob/skills/3d-workflow.md — 8-phase production 3D spec
- Phase 1: Concept and blockout
- Phase 2: Topology (quad mesh, edge flow)
- Phase 3: UV unwrap (0–1 space, no overlaps)
- Phase 4: PBR texturing (albedo, roughness, metalness, normal)
- Phase 5: Lighting (3-point rig)
- Phase 6: LOD chain (LOD0/1/2 poly budgets)
- Phase 7: Code architecture (Three.js or bpy integration)
- Phase 8: Export (glTF 2.0, compressed)

### tools/validate-mesh.mjs — OBJ mesh validation script
- Checks vertex count, face count, UV presence
- Reports non-manifold edges
- Returns pass/fail with structured output

### .bob/rules/shaders.md — 6-shader library
- Unlit flat colour
- Lambert diffuse
- PBR (metalness/roughness workflow)
- Toon / cel-shaded
- Emissive glow
- Wireframe overlay

### .bob/rules/rig.md — Canonical 3-point rig
- Key light, fill light, rim light positions
- Bpy (Blender Python) implementation
- Three.js DirectionalLight implementation

### .bob/skills/taste-library.md — 4 new 3D entries added
- Added isometric game art, low-poly, toon shading, and PBR office references
