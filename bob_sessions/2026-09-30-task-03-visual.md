## What Bob built

### .bob/skills/visual-quality-gate.md — 5-phase AAA visual quality skill
- Phase 1: Concept audit (typography, spacing, hierarchy)
- Phase 2: Colour and contrast checks (WCAG AA)
- Phase 3: Component consistency pass
- Phase 4: Motion and interaction review
- Phase 5: Final score gate (must reach threshold before declaring done)

### .bob/skills/taste-library.md — Visual taste reference corpus
- 16-entry seed corpus of design reference patterns
- Covers typography, colour, layout, motion, iconography
- Used by the quality gate and Visual Director mode to anchor decisions

### .bob/rules/visual.md — 5 non-negotiable visual gates
- No font-weight outside 400/500/600/700/800
- No colour contrast below 4.5:1 on body text
- No layout shift on interaction
- No placeholder content in shipped views
- No unsupported CSS values (the font-weight: 750 bug this project started with)

### .bob/commands/score.md — /score command
- Runs the 5-phase quality gate on the active file or component
- Returns a numeric score and a list of violations

### .bob/modes/visual-director.yaml — Visual Director mode
- Focused mode for UI review and improvement work
- Loads taste-library and visual rules automatically
