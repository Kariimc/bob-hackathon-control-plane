## What Bob fixed

### lib/router.mjs — Async handler leak
- **Bug:** async route handlers that threw would produce unhandled Promise rejections
  instead of forwarding the error to the `onError` callback
- **Fix:** wrapped async dispatch in `.catch(onError)` so all async errors are forwarded

### public/app.js — innerHTML XSS pattern
- **Bug:** task title and owner were being injected into the DOM via `innerHTML`,
  creating a stored XSS vector for any task title containing HTML
- **Fix:** replaced all `innerHTML` assignments in the pipeline rail with
  `textContent` and `createElement` / `appendChild`

### server.mjs — STORE_PATH env variable not wired
- **Bug:** the `STORE_PATH` environment variable was read but never passed through
  to `createStore()`, so persistence silently fell back to in-memory on every start
- **Fix:** wired `process.env.STORE_PATH` through `startServer()` to `createAppServer()`
  to `createStore()`

### public/app.js — Timestamp refresh interval
- **Bug:** relative timestamps ("2 minutes ago") were only computed once on render
  and never refreshed, so they stayed stale indefinitely
- **Fix:** added a `setInterval` to re-render timestamps every 30 seconds

### lib/store.mjs — Flush debounce
- **Bug:** every mutation triggered an immediate disk write, causing many rapid writes
  when tasks were created or advanced in quick succession
- **Fix:** added a 50ms debounce so rapid mutations are coalesced into one write

### public/app.js — SSE reconnection backoff
- **Bug:** on SSE disconnect the client reconnected immediately and repeatedly,
  flooding the server with reconnect attempts
- **Fix:** added exponential backoff (5 retries, delays: 1s, 2s, 4s, 8s, 16s)
